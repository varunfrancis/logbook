What stays private

  • Everything runs on your Mac. Nothing is uploaded and there's no account.
  • It reads your Claude Code history and git on this computer.
  • Friendly building names come from the small Claude model through your own Claude Code login, which uses a tiny amount of your usage.
  • Share cards never include repo names, files or prompts.

What you need

  • A Mac (Apple silicon or Intel).
  • Claude Code, in the Claude desktop app or the terminal.
  • Optional: VS Code, so Swarmville can open agents right inside it.

Update or remove

Ask Claude to "update Swarmville" or "uninstall Swarmville". Or run ~/.logbook/bin/logbook update or ~/.logbook/bin/logbook uninstall --everything.
